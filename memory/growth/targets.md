## Categories

### 1. Self-publishing platforms

The highest-leverage category. If a self-publishing platform surfaces PagePerfect inside its workflow (as a recommended PDF tool, a partner, a listed integration), every author using that platform sees us.

- **Amazon KDP** — KDP Community resources, KDP help-page tool mentions, partner listings. The largest single audience.
- **IngramSpark** — partner directories, content marketing relationships. Trade-distribution audience.
- **Lulu** — already integrated via xPress API; deeper partner / co-marketing surface.
- **Reedsy** — author-tooling marketplace; "Reedsy Tools" directory and editorial.
- **Draft2Digital / Smashwords** — distribution platforms; tooling listings.
- **BookBaby / Lulu / Blurb** — turnkey self-publishing services with their own tool ecosystems.

Integration shapes: API submission, KDP "Look Inside" upload assist, IngramSpark / Lulu cover dimension calculator embed, Reedsy listing.

### 2. Author tools + writing platforms

Tools where authors finish manuscripts before they need typesetting.

- **Writing tools** — Scrivener, Ulysses, iA Writer, Obsidian, Typora: Markdown-native or export to Markdown. Natural upstream of PagePerfect.
- **Story tools** — Plottr, Dabble, Novlr: structure-focused; their users hand off to a typesetter.
- **Editing tools** — ProWritingAid, Grammarly, AutoCrit: their power users are pre-publishers.
- **Workflow tools** — Notion, Roam: authors who outline there will export and typeset elsewhere.

### 3. Author communities + organisations

Communities that run programmes, conferences, or referral networks for self-published authors.

- **IBPA (Independent Book Publishers Association)** — member directory, partner discounts, conference sponsorships.
- **ALLi (Alliance of Independent Authors)** — partner directory, advice-line tool recommendations.
- **SFWA / MWA / RWA** — genre-specific guilds (SF/F, mystery, romance).
- **NaNoWriMo** — annual cycle; high-volume manuscript-to-book funnel.
- **Self-Publishing School (Chandler Bolt)** — high-volume author training; tool recommendations.

### 4. Grant programmes (non-platform)

- **Mozilla Open Source Support (MOSS)** — open-source infrastructure grants if PagePerfect's open-core meets criteria.
- **NLnet Foundation** — open-source / privacy-respecting tooling grants.
- **Sloan Foundation / Knight Foundation** — publishing-adjacent culture/tech grants (long-shot).
- **GitHub Sponsors, Open Collective** — continuous funding if open-source core is published.
- **Arts Council England / Creative Europe** — long-shot, would require UK/EU residency alignment.

### 5. Typography + design community

Potential collaborators, integration partners, and distribution channels via their audiences.

- **TypeNetwork, Type@Cooper, OH no Type Co, Pampatype** — type foundries with author audiences (font-licensing partnerships).
- **Penguin, Faber, Cambridge UP, Princeton UP, MIT Press** — trade and academic publishers with internal production teams (long-shot B2B).
- **Boutique book designers** — individual practitioners; potential partnerships rather than competitors.
- **Bookbinding / printing trade associations** — BookManufacturers' Institute, PIA.

Outbound is relationship-first. Ask for a follow-up chat, not for a listing.

### 6. Press + media

(Mostly owned by marketing's `outreach` skill. Growth coordinates on the announcement side.)

- **Self-publishing trade** — Publishers Weekly, BookBusiness, Jane Friedman's newsletter, Joanna Penn (The Creative Penn), Self-Publishing School podcast.
- **Author-facing podcasts** — Self-Publishing Show, Six Figure Authors, Sell More Books Show.
- **General writing press** — The Bookseller (UK), Writer's Digest, Poets & Writers.
- **Not-in-Scope-Yet**: traditional mainstream outlets (FT, WSJ, Wired) — only post-milestone events.

### 7. Directories + listings

- **Reedsy "Tools" directory** — author-tool comparison.
- **AlternativeTo, G2, Capterra** — software comparison sites; especially the Vellum / Atticus comparison slots.
- **awesome-selfhosted, awesome-markdown, awesome-pandoc, awesome-typst, awesome-writing-tools** — curated GitHub lists.
- **Product Hunt** — launch-week visibility.

### 8. Educational platforms

- **Self-publishing courses** — Self-Publishing School, Mark Dawson's Self-Publishing Formula, 20Booksto50K group programmes.
- **University publishing programmes** — Pace University, NYU SPS, Stanford Continuing Studies — long-shot but high-leverage if a programme adopts PagePerfect as recommended typesetting.
- **MFA programmes** — niche; mention only.

### 9. Developer platforms (B2B / API surface)

- **Pandoc community** — PagePerfect's pipeline includes Pandoc; tutorial cross-referencing has natural fit.
- **Typst community** — same logic; we use Typst as PDF engine.
- **Markdown ecosystem** — `awesome-markdown`, Markdown Guide, CommonMark.
- **API marketplaces** — RapidAPI, Postman Public Workspace (if/when we ship a public API tier).

## Selection criteria

Before any outbound, the skill (`integration-proposal`, `partnership-brief`, etc.) checks:

1. **Segment fit.** Does the target serve our audience segments (see `memory/marketing/audiences.md`)?
2. **Mutual value.** What do we offer them? What do they offer us? Balance.
3. **Timing.** Are they in a period where integrations / listings / grants are being evaluated?
4. **Jurisdiction.** Does partnering / receiving funds from this target create a cross-border issue?
5. **History.** Have we already approached this target? See `partnerships-history.md`. Avoid double-sending.

## How this file is maintained

- **Add** when a target surfaces from `market-research`, a user request, or a partnership inbound.
- **Remove** when a target sunsets (platform deprecated, programme ends). Mark retired; keep historic reference.
- **Update contact + programme info** when a target's approach changes (new grant cohort, new application link, new editorial lead).

Every material update cites a source + date.

## Priority tiers

Not every target is worth pursuing now. Tier them.

- **Tier 1 — active.** We are pursuing this target this quarter. Resources allocated.
- **Tier 2 — warm.** We plan to pursue within 6 months. Relationship groundwork possible now.
- **Tier 3 — monitored.** We are not pursuing; we track for changes.
- **Not pursuing — banned.** Out of scope by policy (crypto / Web3 / DeFi ecosystems; see `partnership-brief` hard-bans).

Initial tiering of categories above to be done in `partnerships-history.md` + `grants-history.md` as each target is first engaged.
